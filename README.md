# Disney Retirement Family Trip Site

Small static website for the Malin family Orlando / Disney retirement trip in October 2026.

Hosted using GitHub Pages:

* HTML + embedded CSS only
* No frameworks
* No build tools
* No dependencies
* Simple standalone webpages

## Live Site

https://martialart33.github.io/disney-retirement-trip/

---

## Purpose

This site is used to share:

* trip overview
* week-at-a-glance itinerary
* flexible activity and adventure ideas
* planning updates
* flight and rental vehicle information
* travel group and lodging information

The public page is family-facing. A separate full planning page contains private budgeting and financial information.

| File | Purpose |

---

## Updating the Site

1. Update `index.html` for the public family-facing page.
2. Update `retirement_family_trip_FULL.html` when internal planning details also change.
3. Commit changes to the `main` branch.
4. GitHub Pages automatically republishes the public site.

Usually updates appear within a few minutes.

---

## Trip Planning Approach

The October 5–12, 2026 family trip is intentionally flexible.

Only the travel days and Tuesday Relax & Recharge are scheduled. Wednesday through Sunday remain open so the family can choose activities based on energy, weather, crowds, and what sounds fun at the time.

The site includes a **Choose Your Adventure** section with possible activities rather than assigning those activities to specific days.
