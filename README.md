# Disney Retirement Family Trip Site

Small static website for the Malin family Orlando / Disney retirement trip in October 2026.

Hosted using GitHub Pages:

* HTML + embedded CSS only
* No frameworks
* No build tools
* No dependencies
* Just a simple standalone webpage

## Live Site

https://martialart33.github.io/disney-retirement-trip/

---

## Purpose

This site is used to share:

* trip overview
* itinerary
* activity ideas
* planning updates
* travel group information

A separate internal planning version contains budgeting and financial information and is not published publicly.

---

## Repository Contents

| File                       | Purpose                                     |
| -------------------------- | ------------------------------------------- |
| `index.html`               | Public family-facing trip itinerary webpage |
| Internal planning versions | Budgeting and working-planning copies       |

---

## Updating the Site

1. Edit `index.html`
2. Commit changes to the `main` branch
3. GitHub Pages automatically republishes the site

Usually updates appear within 1–2 minutes.

---

## Tech Notes

This intentionally uses:

* standalone HTML
* embedded CSS
* no JavaScript frameworks
* no external libraries

The goal is:

* simple
* portable
* printable
* easy to maintain long-term

Basically:

> “Old-school web done on purpose.”
